プライバシーポリシー

対象：おっず分配
作成日：2026年10月30日
運営者：KENdmyy

入力した情報

選択した買い目と分配結果は端末のメモリ上で処理し、開発者が運営するサーバーへ送信しません。分配結果の履歴は保存しません。カスタム予算・目標金額は端末内に保存します。アカウント登録、位置情報、カメラ、マイクへのアクセスは求めません。

小窓のための参照動画を端末のアプリ用領域へ作成します。利用者や画面を録音・録画するものではありません。コピー操作は利用者が指示した場合にクリップボードへ内容を書き込みます。

オッズの取得

開催情報とオッズの取得時にJRAの公開ページへHTTPSで通信します。通信先はIPアドレス等の通常の通信情報を受信します。提供元での情報の扱いは、JRAの案内もご確認ください。

広告と同意管理

広告配信にはGoogle AdMob（Google Mobile Ads SDK）を、同意管理にはGoogle User Messaging Platformを使用します。配信、広告効果測定、診断、不正防止などのため、IPアドレス、端末情報、広告表示・操作情報、診断情報などがGoogleや広告配信事業者へ送信される場合があります。

アプリは広告を非パーソナライズ指定で要求し、Publisher first-party IDを無効にします。アプリからATTの追跡許可や広告識別子の取得は求めません。ただし、広告SDKによるデータ送信が一切ないことを意味するものではありません。

必要な地域では広告要求前に同意確認を行います。広告のプライバシー設定の再表示が必要な場合、アプリの歯車メニューに設定ボタンを表示します。広告非表示の購入を確認できた利用者には広告を要求しません。

  • Googleのプライバシーポリシー
  • Googleによる広告での情報利用

アプリ内購入

広告非表示の購入と復元はAppleのApp Storeを通じて行います。アプリは検証済みの購入情報を利用して広告非表示の状態を確認します。開発者がクレジットカード情報やApple Accountのパスワードを取得することはありません。

お問い合わせ

メールでのお問い合わせでは、返信に必要なメールアドレスと、利用者が送信した内容を受信します。これらは対応と不具合調査のために利用します。

kendmyy@gmail.com

端末内データの削除と変更

アプリの削除により、端末内のアプリ用データを削除できます。Appleが管理する購入履歴は、アプリの削除では消えません。本ポリシーは機能や利用サービスの変更に合わせて更新します。

このサポートサイト

GitHub Pagesでホストしています。このページには開発者独自の広告・アクセス解析コードを追加していません。ホスティング事業者は通信やセキュリティのための情報を取り扱います。
